# Smart Dustbin Using GSM

## Project Overview
The Smart Dustbin Using GSM is an embedded systems project developed during my Diploma in Engineering.

The project aims to improve waste management by monitoring the garbage level inside a dustbin and providing alerts through GSM communication.

## Objectives
- Monitor garbage levels inside the dustbin.
- Detect when the dustbin reaches its predefined filling level.
- Send alerts through GSM communication.
- Reduce manual garbage-level inspection.
- Support smarter and more efficient waste management.

## Technologies Used
- Embedded C
- GSM Communication
- Microcontroller: Arduino-UNO-R3
- Sensors: HC-sr04,servo motor(SG90 micro servo)
- GSM Module:SIM900A


## Working Principle
1. The sensor monitors the garbage level.
2. The microcontroller processes the sensor readings.
3. When the garbage reaches the configured threshold, the system triggers an alert.
4. GSM communication is used to send a notification to the configured mobile number.

## Applications
- Smart cities
- Public garbage collection systems
- Residential societies
- Commercial buildings
